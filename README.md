# Sheets Dashboard — версия без фреймворков

Тот же дэшборд из Google Таблиц и файлов, но на голом JS: ни Vue, ни Vite,
ни сборки. Браузер грузит `index.html` и ES-модули из `js/` напрямую.

## Запуск

Модули не работают по `file://` — нужен любой локальный сервер:

```bash
python3 -m http.server 8000      # или: npx serve .
```

Затем `http://localhost:8000`.

## Публикация

Положить файлы в репозиторий GitHub и включить **Settings → Pages → Source →
Deploy from a branch → main / (root)**. Никаких GitHub Actions: собирать нечего,
это уже готовая статика. Так же работает любой веб-сервер — просто скопировать
папку.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка-заглушка, подключение стилей и точки входа, тема до первого рендера |
| `css/style.css` | палитра (светлая/тёмная), общий хром и стили всех блоков |
| `js/app.js` | состояние, загрузка данных, рендер лендинга и дэшборда |
| `js/dom.js` | `h()` и `s()` — создание HTML- и SVG-узлов вместо шаблонов |
| `js/gviz.js` | чтение Google Таблиц через публичный gviz-эндпоинт |
| `js/fileLoad.js` | CSV/TSV-парсер, чтение Excel, определение типов колонок |
| `js/analyze.js` | классификация колонок, фильтры, бакеты времени, агрегаты |
| `js/charts.js` | линейный график, горизонтальные бары, спарклайн |
| `js/ui.js` | KPI-плитка, карточка графика, легенда, таблица, фильтры, тема |
| `js/format.js` | форматирование чисел и дат (ru-RU) |
| `js/scale.js` | «красивые» деления оси, отслеживание ширины контейнера |

## Отличия от Vue-версии

- **Нет реактивности.** Состояние — обычный объект `state` в `app.js`; после
  изменения вызывается `render()` (весь экран) или `renderDash()` (только
  содержимое дэшборда). Наборы данных здесь небольшие, полная перерисовка
  дешевле, чем ручное сравнение.
- **Excel грузится с CDN.** `js/fileLoad.js` делает
  `import('https://cdn.sheetjs.com/…/xlsx.mjs')` в момент, когда пользователь
  бросил `.xlsx`. Для CSV и Google Таблиц не грузится ничего лишнего. Если
  нужна работа офлайн — скачать `xlsx.mjs` в `js/vendor/` и поменять константу
  `XLSX_CDN` на локальный путь.
- **Стили в одном файле.** У Vue они были `scoped`; при слиянии пришлось
  развести пересечения — в частности, тире между датами получило класс
  `.range-dash`, потому что `.dash` уже занят контейнером дэшборда.
- **Виджеты с `ResizeObserver`** помечены `data-widget` и хранят отписку в
  `__dispose`; `setChildren()` из `dom.js` вызывает её перед заменой узлов.

## Требования к таблице

- Первая строка — заголовки колонок (или закреплённая строка заголовка).
- Доступ: Файл → Настройки доступа → «Все, у кого есть ссылка» → Читатель.
- Лист выбирается параметром `#gid=…` в ссылке; без него берётся первый.

Ссылкой на готовый дэшборд можно делиться: `?sheet=<ссылка на таблицу>`.
Учтите, что такая ссылка содержит адрес таблицы — переслав её, вы пересылаете
и доступ к данным.

## Тесты

`smoke.mjs` — необязательный смоук-тест логики и рендера (разбор gviz и CSV,
вывод типов, агрегаты, полный рендер дэшборда, фильтры, тултипы). Единственная
зависимость нужна только ему:

```bash
npm i jsdom && node smoke.mjs
```

Самому приложению npm не нужен.
